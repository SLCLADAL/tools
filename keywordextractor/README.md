# KeywordExtractor: A Browser-Based Tool for Keyness Analysis and Distinctive-Vocabulary Extraction

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.22970124.svg)](https://doi.org/10.5281/zenodo.22970124)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

KeywordExtractor is a browser-based Shiny application for keyness analysis: identifying vocabulary that is statistically over- or under-represented in a target corpus compared with a reference corpus. It computes log-likelihood, chi-squared, and log-ratio effect sizes using the quanteda toolkit, and displays results as sortable, filterable tables with adjustable significance thresholds. Suitable for teaching and research in corpus linguistics, sociolinguistics, discourse analysis, and the digital humanities.

Part of the [LADAL Tools](https://ladal.edu.au/tools.html) suite developed at
the Language Technology and Data Analysis Laboratory (LADAL), The University
of Queensland.
